    Generate Quiz Code

    Compresses (gzip) and encodes (AES-256-GCM, PBKDF2-derived key) the current quiz into a Base64URL Quiz Code, compatible with offline-quiz-runner.html. By default the secret key travels inside the same code — one string to copy and share, but not private, since anyone holding it can decode it.
