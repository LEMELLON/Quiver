How the Quiz Code format works

The quiz JSON is compressed with the browser's native CompressionStream('gzip'). The compressed bytes are encrypted with AES-GCM (256-bit) using a key derived from your passphrase via PBKDF2 (150,000 iterations, SHA-256) with a random 16-byte salt and a random 12-byte IV. The salt, IV, and ciphertext are concatenated and encoded as Base64URL — that concatenated string is the "Quiz Code". Nothing leaves the browser; everything runs through window.crypto.subtle and native stream APIs.
